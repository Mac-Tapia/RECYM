Tutorial 
Utilización de Python® en CYME 
– CYME 8.0 
 
 Se proporciona un fichero de estudio autónomo (.sxst) para ser utilizado con este tutorial. Las explicaciones de abajo se basan en el 
uso de dicho fichero. 
1. Introducción a Python® en CYME 
 Cuando se usa el programa CYME se pueden crear scripts para automatizar las tareas con el lenguaje Python. El 
módulo puede ser utilizado de diferentes maneras: 
• Incorporándolo en CYME 
• Como ejecutable externo de Python 
En este tutorial sólo se explica el primer método. El segundo es para los usuarios avanzados.  
También se describen los componentes siguientes:  
• la barra de herramientas de Python 
• la consola de Python 
• el cuadro de herramientas Python 
Las herramientas de Python se pueden acceder escogiendo la opción de menú Archivo > Herramientas > Consola 
Python o Cuadro de herramientas Python. 
Para agregar la barra de herramientas, pulse el botón derecho del ratón sobre un espacio vacío de la barra de 
herramientas y seleccione Python en la lista de barras de herramientas. La barra siguiente aparecerá. 
 Las opciones siguientes estarán disponibles en la barra de herramientas, de izquierda a derecha: 
• cuadro de selección de los scripts del cuadro de herramientas 
 • botón Ejecutar el script Python 
• botón Abrir el cuadro de herramientas Python  
• botón Abrir la consola Python 
• botón Abrir el editor Python 
 
 Abra el estudio autónomo python-s.sxst disponible con este tutorial.

3. Cuadro de herramientas Python  
 El cuadro de herramientas Python puede servir para 
guardar y ejecutar scripts. El cuadro de herramientas 
se puede abrir desde la barra de herramientas o 
desde el menú Archivo > Herramientas > Cuadro de 
herramientas Python.  
El cuadro de diálogo siguiente se abrirá. Éste contiene 
algunos ejemplos de scripts.  
La barra de herramientas disponible en el cuadro de 
diálogo contiene las siguientes opciones, de izquierda 
a derecha: 
1. Mostrar el menú opciones 
2. Agregar el script Python 
3. Modificar las propiedades del script Python 
4. Quitar el script Python 
5. Ejecutar el script Python 
6. Editar el script Python 
7. Importar/Exportar Script Python 
8. Opciones de búsqueda 
Seleccione el script Summary Report LF/SC y 
ejecútelo. Un informe personalizado deberá aparecer 
al terminar la ejecución. También podrá visualizar el 
script seleccionando la opción Editar el Script 
Python.
