Tutorial 
Primeros pasos con una base de datos 
– CYME 8.0 
 
 En el paquete de instalación de CYME se proporciona una base de datos del tutorial para ser utilizada con este tutorial. Las 
explicaciones dadas a continuación se basan en el uso de esta base de datos. 
1. Definir la Configuración en CYME 
 Los archivos de configuración de CYME sirven para guardar los diferentes parámetros de la aplicación tales como las 
opciones de visualización, los parámetros de cálculo, las configuraciones de las bases de datos, etc. Por la tanto, es 
importante instalar los archivos de configuración que utilizará CYME. 
Usted puede crear su propia configuración que podrá luego distribuir a los demás usuarios, y en consecuencia 
promover el uso de estándares.

ejecutable Cymconfig.exe.

 Al pulsar Terminar, el Asistente de la base de datos de CYME se cierra y su 
nueva configuración de base de datos se agrega a la pestaña Bases de 
datos de la Barra de exploración. 
El “Nombre de configuración de la base de datos” es el nombre que aparece 
en la pestaña Bases de datos de la Barra de exploración o en el cuadro de 
lista desplegable de la barra de herramientas Base de datos. 
 
 
 Es posible cambiar la configuración de la base de datos a medida que los proyectos y los estudios cambian. Ver el 
cuadro de diálogo Base de datos > Administrador de la base de datos. 
3. Primeros pasos con CYME 
 
 
Al abrir CYME, el fondo de la ventana es gris y la mayoría de los iconos de la barra de herramientas y de los 
comandos del menú están desactivados. Para activar todas las funciones de la aplicación e iniciar un estudio, 
haga clic sobre el icono Nuevo estudio o seleccione el menú Archivo > Nuevo estudio.

5. Guardar/Cerrar un Estudio, y Actualizar redes 
 
a. En la barra de herramientas, pulse el icono Guardar estudio 
  en la barra de herramientas Principal, o escoja 
el comando Archivo>Guardar estudio como. 
 b. Ingrese un nombre de archivo de estudio (“Tutorial” por ejemplo) en el campo Nombre de archivo (File name) y 
pulse Grabar (Save). 
 c. Para abrir un estudio, usted necesita primero cerrar el estudio activo. Para esto, seleccione el menú 
Archivo>Cerrar estudio. 
La ventana principal de CYME se desactivará entonces (tornándose gris) así como la mayoría de los botones de 
las barras de herramientas y de las opciones de los menús. 
 d. Guardar un estudio auto-contenido – La segunda manera de guardar los cambios hechos a los circuitos es de 
guardar un estudio auto-contenido. 
Las etapas para guardar y abrir un estudio auto-contenido son exactamente las mismas que con un solo estudio. 
La única diferencia es que al abrir un estudio auto-contenido usted no necesita estar conectado a la base de datos 
que fue creada simultáneamente. El estudio es autónomo, lo que significa que contiene todas las informaciones 
para reproducir la red que fue cargada cuando el estudio fue guardado. 
 e. Actualizar la red – La tercera manera de guardar los cambios hechos a los circuitos con CYMDIST es 
actualizando la base de datos con el comando Archivo>Base de datos>Actualizar red. Esto grabará de manera 
permanente en la base de datos todas las modificaciones realizadas.
