# Informe de entrega (producto operativo)

**No confundir con el artículo científico.**  
Artículo IEEE → carpeta `docs/articulo_ieee/` · Separación → [`docs/SEPARACION_INFORME_ARTICULO.md`](../docs/SEPARACION_INFORME_ARTICULO.md)

## Qué es

Documento de **modelo y resultados de una ejecución** RECYM/CYMDIST para un alimentador y una solicitud concreta (factibilidad / punto de diseño). Incluye antecedentes del interesado, análisis de tensión y cargabilidad situacional vs proyectado, conclusiones y recomendaciones de entrega.
